# APCS - Advanced Principles of Computer Programming

This repository contains my solutions to the **APCS (Advanced Principles of Computer Programming)** problems. APCS is a standardized exam in Taiwan used to assess high school students' programming and problem-solving skills.

## 🚀 About My Progress
I focus on implementing robust solutions with a strong emphasis on **Defensive Programming** and **Algorithmic Efficiency**. My journey includes moving from basic simulations to deriving complex graph algorithms independently.

### 🏆 Featured Challenges
* **[g276] King's Maze (Simulation)**: Implemented a multi-stage simulation involving bomb placement, coordinate movement, and collision detection. Mastered the logic of "Move first, Judge later" to handle simultaneous events.
* **Graphic Sequence Problem (Havel-Hakimi Algorithm)**: Independently derived a greedy strategy to determine if a degree sequence can form a simple graph. Successfully optimized the solution from $O(N^2)$ to $O(N \log N)$ to avoid TLE.
* **Matrix Transformations**: Solved matrix flipping and rotation problems using generalized index formulas rather than hard-coded logic.

## 🛠️ Skills Demonstrated
* **Time Complexity Optimization**: Identifying and removing redundant loops within $O(N)$ processes.
* **Edge Case Handling**: Implementing boundary checks to prevent Buffer Overflows and Runtime Errors.
* **Data Structures**: Proficient use of `std::vector`, `std::sort`, and 2D arrays in C++.
* **Logical Reasoning**: Breaking down complex word problems into distinct execution phases (e.g., Simulation -> Evaluation -> Cleanup).

## 📂 Structure
Each folder is named after the problem ID (e.g., `g276/`) and contains:
* `solution.cpp`: The AC-verified source code.
* `notes.md`: (Optional) Brief reflection on the problem logic or tricky edge cases.
